## API/data contract P1
POST /api/auth/signup JSON fields; 202 generic duplicate response, atomic user/workspace/membership/challenge/delivery/audit. POST login returns no secrets, sets cookie. GET /api/me returns user + accessible workspaces + active membership. POST /api/auth/logout clears server session. POST request-reset always 202, POST reset consumes token+password atomically and revokes sessions. POST verify single-use token; POST resend authenticated with cooldown. GET/PATCH /api/workspace resolve tenant from session (ignore/reject client tenant data). POST /api/workspace/switch verifies fresh membership and changes session; clients remount state. GET /api/members; POST invite; PATCH role/status checks last owner and current role. GET audit read-only metadata. Errors {error,fields?}, 400 invalid,401 unauthenticated,403 forbidden,409 conflict,429 throttled,500 generic. Transactions roll back on all errors; audit contains event/object IDs, never password, token or message body.
