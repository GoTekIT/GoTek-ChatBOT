# D010 / H28.03 scoped support
Workspace Owner/Admin issues grant to an existing active platform administrator, reason 5–500 characters, expires 5–60 minutes (provisional GoTek local/test policy). Scope currently operational_metadata only, returning workspace name/status and aggregate job-state counts. Content scope unsupported/default deny until conversation storage exists; never interpret metadata grant as chat permission. Grant is workspace-bound, subject-bound, time-bound, revocable, and logged on create/revoke/use. Platform admin cannot issue a grant through platform API; ordinary workspace role required. GET support metadata checks active role + grant each request before setting tenant context. Restore revokes all support grants. UI /settings/support lists/create/revoke with explicit expiry and scope. Platform support viewer accepts grant ID and displays only returned metadata. These are GoTek operational requirements, not observed HiChat parity. Full H28 acceptance includes future content-scope checks and browser evidence.
