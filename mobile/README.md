# GoTek Chatbot - Mobile Client

Thư mục dành cho ứng dụng di động (React Native / Flutter) phục vụ nhân viên hỗ trợ (Support Agent) và quản trị viên (Workspace Admin).

## Tính năng dự kiến:
- Nhận thông báo đẩy (Push Notifications) khi có khách hàng cần hỗ trợ.
- Trò chuyện trực tiếp (Live Chat Hand-off) với khách hàng từ điện thoại.
- Chuyển tiếp hội thoại (Conversation Routing) và gán tag.
- Quản lý quy tắc AI và bật/tắt chế độ tự động trả lời.
